Root Cause Analysis:
Tests C10, C11, C12 were failing due to a race condition with Next.js App Router's
async navigation. The application's `<Link>` and `router.push()` transitions happen
asynchronously (RSC fetch inside useTransition), but the test assertions checked
page.url() immediately after the click, before the transition completed.

Fix Applied:
Added `await page.waitForURL(targetPath, { timeout: 5000 })` guards after each navigation,
following the same pattern established in home.spec.ts and login.spec.ts. This ensures
the navigation transition completes before assertions run.
