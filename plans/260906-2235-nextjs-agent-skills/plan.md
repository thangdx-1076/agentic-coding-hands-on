# Vendor three agent skills

## Why

Add Vercel's `vercel-react-best-practices`, `vercel-react-view-transitions`,
`vercel-composition-patterns` skills to `.claude/skills/` so every clone of
this repo gets them, without disturbing the 5 hand-authored skills already
committed there.

## Decisions already made (do not re-litigate)

- Install via `npx -y skills@1.5.23 add vercel-labs/agent-skills -s vercel-react-best-practices -s vercel-react-view-transitions -s vercel-composition-patterns --copy -y -a claude-code` (repeat `-s` per skill — a comma-separated `--skill` list is rejected; `--copy` gives real dirs, not symlinks).
- Scope: project-level, `.claude/skills/`, exactly these 3 skills, nothing else.
- No F### feature spec — this is tooling, not product behavior.

## Key repo facts (verified 2026-09-06)

- `.gitignore` re-ignores everything under `.claude/skills/*` and un-ignores
  each hand-written skill by name (lines 60-65). **New skill dirs are
  invisible to git until unignored the same way** — this is the one step
  most likely to be silently skipped.
- `.prettierignore` and `eslint.config.*` (`globalIgnores([".claude/**", ...])`)
  already exclude all of `.claude/`, so `pnpm format:check` / `pnpm lint`
  need **no new entries** — vendored markdown is skipped by default.
- No doc anywhere lists a "skill inventory" — nothing in `docs/` to update.
- `AGENTS.md` is regenerated by `next dev`; do not touch it.
