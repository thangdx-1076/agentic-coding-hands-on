## Test Fixes Applied

### 1. Selector Scoping (TC 8415b629, TC 20d87e28)
**Problem:** `button[aria-haspopup="menu"]` matched both app language selector AND Next.js dev-overlay  
**Solution:** Scoped to `header button[aria-haspopup="menu"]`

### 2. Alert Filtering (TC 45278c06)
**Problem:** `[role="alert"]` matched error message AND Next.js route announcer  
**Solution:** Changed to `p[role="alert"].filter({ hasText: /Đăng nhập không thành công/ })`

### 3. Button Loading State (TC 37eae882)
**Problem:** Route interception inside test assertions caused page detach  
**Solution:** Used `page.exposeFunction` + `MutationObserver` to observe button state from page context (survives navigation). Route fulfilled with stub HTML instead of abort.

### 4. Authenticated Tests (TC f62b0c97, TC e76aa170)
**Problem:** Session cookies not recognized by @supabase/ssr library  
**Solution:** Used library's `setSession` method via `createServerClient` to generate cookies in correct format, then injected into browser context with domain=`localhost`, path=`/`.
